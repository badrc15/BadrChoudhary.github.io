# Badr Choudhary — portfolio

A lightweight portfolio built with plain HTML, CSS, and JavaScript. It links to four projects and uses an existing screenshot of the Crypto Dashboard desktop app.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

The site files are in the `docs` folder because the repository's GitHub Pages deployment source is `main` → `/docs`. GitHub Pages serves the site at `https://badrc15.github.io/BadrChoudhary.github.io/`.

Project and social links are configured in `script.js`.
