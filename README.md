# Badr Choudhary — portfolio

A lightweight portfolio built with plain HTML, CSS, and JavaScript. It links to four projects and uses an existing screenshot of the Crypto Dashboard desktop app.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

This site is prepared for the existing `badrc15/BadrChoudhary.github.io` repository. Copy `index.html`, `styles.css`, `script.js`, and the existing `images/CryptoProject.jpg` into its root, then select **Settings → Pages → Deploy from a branch → main → /(root)**. Once deployment completes, the project site URL is `https://badrc15.github.io/BadrChoudhary.github.io/`.

Project and social links are configured in `script.js`.
